A GOOD FIRST TEST

Start with the signal.

  1. Check both fields. Healthy means MD = 1, ML = 0 and MH = 0. Correct the magnet alignment and gap before calibrating.
  2. Set two endpoints. Let go and capture release. Pull to a comfortable mechanical stop and capture full pull. Repeat for the other lever.
  3. Pull and release ten times. Look for a smooth trace and a repeatable return. Unplugging a sensor or losing Bluetooth should show a fault, never a healthy held reading.
